Descripción del Curso
Sumilla
El curso desarrolla diversos temas seleccionados para que los estudiantes puedan familiarizarse con marcos de trabajo utilizados hoy en día para la implementación de aplicaciones Web empresariales. Las aplicaciones Web empresariales se desarrollan frecuentemente para permitir que las organizaciones puedan extender sus servicios hacia lugares y publico distante gracias a la plataforma de Internet, de esta manera pueden ofrecer servicios y productos a un mayor número de potenciales clientes, quienes pueden realizar transacciones y pagos en línea en forma rápida esto permite que las empresas puedan ampliar las líneas de productos y servicios que ellos ofrecen, pero por otro lado es necesario que la aplicación web desarrollada permita almacenar toda la información requerida en forma segura y que a su vez la aplicación sea una solución escalable y por tanto pueda crecer en el tiempo, según las necesidades de la empresa.

Capacidades Terminales
•	Identificar los principales marcos de trabajo para desarrollo de aplicaciones Web empleando el lenguaje PHP
•	Implementar aplicaciones Web empresariales empleando herramientas de programación modernas
•	Utilizar bases de datos y servicios web en las aplicaciones empresariales
•	Implementar aplicaciones Web para comercio electrónico
